# Что должна уметь наша минимальная ORM (Идея для PR-08)

1. **# Описывать структуры таблиц прямо в классах:**
   Чтобы не писать SQL-запросы вручную, мы задаём метаданные таблицы (table_name, primary_key, fields) прямо внутри Python-классов через наследование от базовой модели Model.
2. **Сама собирать SQL-запросы:**
   Нам больше не нужно вручную склеивать строки `INSERT INTO...` или `UPDATE...`. ORM должна сама смотреть на имя класса и его поля и на лету генерировать правильный SQL-код под нужную операцию.
3. **Различать создание и обновление объектов:**
   При вызове метода save() ORM сама проверяет наличие первичного ключа (id). Если его нет — выполняется INSERT, а если объект уже существует в базе — выполняется UPDATE.
4. **Предоставлять единый API для работы с данными:**
   Все базовые операции с БД (save, delete, get, all) доступны прямо из моделей без использования внешних репозиториев, что избавляет прикладной код от ручной работы с SQL.
