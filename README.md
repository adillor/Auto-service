# AutoService

Учебный проект по разработке объектно-ориентированного приложения для автосервиса на Python.

Проект показывает постепенное развитие приложения: от предметной объектной модели до работы с PostgreSQL, собственной ORM, SQLAlchemy и REST API на FastAPI.

## Возможности

Приложение позволяет работать с основными сущностями автосервиса:

- клиентами;
- автомобилями;
- услугами;
- заказами на обслуживание;
- механиками.

Через API можно создать клиента, добавить ему автомобиль, создать услугу и оформить заказ. Заказ может содержать несколько услуг, а изменение его статуса проверяется бизнес-правилами.

## Технологии

- Python
- PostgreSQL
- psycopg
- SQLAlchemy 2.x
- FastAPI
- Pydantic
- pytest

## Архитектура

Приложение разделено на несколько слоёв:

- `models.py` — SQLAlchemy-модели предметной области;
- `application.py` — прикладная и бизнес-логика;
- `api.py` — REST API на FastAPI;
- `schemas.py` — схемы запросов и ответов API;
- `database.py` — подключение к PostgreSQL и настройка SQLAlchemy;
- `schema.sql` — SQL-схема базы данных;
- `test_*.py` — автоматические тесты.

Полный путь создания заказа:

```text
HTTP-запрос → FastAPI endpoint → прикладной слой →
SQLAlchemy Session → PostgreSQL
```

HTTP-обработчики не содержат SQL и не дублируют бизнес-правила. Проверки и транзакции находятся в прикладном слое.

## Запуск

1. Установите PostgreSQL и создайте базу данных:

```text
autoservice
```

2. Выполните содержимое файла `schema.sql` в созданной базе.

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Запустите API:

```bash
uvicorn api:app --reload
```

После запуска откройте Swagger UI:

```text
http://127.0.0.1:8000/docs
```

## Основные API endpoints

| Метод | URL | Назначение |
| --- | --- | --- |
| POST | `/clients` | Создать клиента |
| GET | `/clients/{id}` | Получить клиента |
| PATCH | `/clients/{id}` | Изменить клиента |
| POST | `/cars` | Создать автомобиль клиента |
| POST | `/services` | Создать услугу |
| POST | `/orders` | Создать заказ с услугами |
| GET | `/orders/{id}` | Получить заказ |
| PATCH | `/orders/{id}/status` | Изменить статус заказа |

## Тесты

Для запуска тестов выполните:

```bash
pytest -q
```

Тесты проверяют работу SQLAlchemy-моделей, бизнес-правил и REST API. Интеграционные API-тесты используют временную SQLite-базу и не изменяют данные PostgreSQL.
