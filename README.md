# Что должна уметь наша минимальная ORM (Идея для PR-08)

1. **Типизировать поля и метаданные в классах:**
   Поля моделей описываются с помощью явно заданных типов (IntegerField, StringField, ForeignKey), из которых базовый класс Model автоматически собирает метаданные таблицы и связей.
2. **Формировать динамическую фильтрацию:**
   ORM сама строит параметризованные SELECT-запросы с условием WHERE, объединяя аргументы через AND и поддерживая операторы сравнения (например, равенство и greater_than).
3. **Управлять связями 1:N и M:N:**
   ORM автоматически получает связанные объекты по внешним ключам (OneToMany) и умеет работать с промежуточными таблицами (ManyToMany) через наглядный API (методы .all() и .add()).
4. **Гарантировать атомарность через транзакции:**
   Операции, затрагивающие несколько таблиц (например, создание заказа вместе с его позициями), выполняются внутри единого контекста transaction(), автоматически откатывая (rollback) изменения при ошибке.
