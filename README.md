# Что должна уметь наша минимальная ORM (Идея для PR-07)

1. **# Описывать структуры таблиц прямо в классах:**
   Чтобы не писать SQL-скрипты вручную, мы должны задавать поля таблицы прямо внутри Python-классов через специальные типы или декораторы.
2. **Сама собирать SQL-запросы:**
   Нам больше не нужно вручную склеивать строки `INSERT INTO...` или `UPDATE...`. ORM должна сама смотреть на имя класса и его поля и на лету генерировать правильный SQL-код под нужную операцию.
3. **Связывать объекты между собой:**
   База данных держится на связях `Foreign Key`. ORM должна уметь автоматически подтягивать связанные сущности. 
4. **Запоминать изменения и работать через сессию:**
   Чтобы не делать лишних запросов в базу при каждом изменении атрибута, ORM должна держать объекты в памяти («сессии»), следить, какие поля изменились (`Dirty Tracking`), и отправлять в БД только итоговые `UPDATE` при вызове `session.commit()`.
